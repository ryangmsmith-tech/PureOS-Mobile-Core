# PureOS Native Runtime Bootstrap — v17.39A

This crate is the first phone-controlled GitHub cloud-build target for the unified Pure OS native runtime line.

## Current purpose

It compiles and tests a native Rust bootstrap contract for:

- Gold Ocean City first slice: 6 of 6 sections merged
- PureRenderIR: v0.8
- Pure Intelligence runtime arbitration: v17.31R
- Aether verification laboratory: v17.38C

## What the cloud build produces

- Linux x86_64 native bootstrap executable
- JSON build evidence generated by that executable
- SHA-256 checksum file
- runtime manifest

## Truth boundary

This build proves that the native bootstrap source compiles and its contract tests pass on GitHub Actions. It does not prove a native GPU frame, desktop presentation, live vehicle physics, headset execution, or production deployment.

## Local commands

```text
cargo fmt --check
cargo test
cargo build --release
./target/release/pureos-native-runtime-bootstrap pureos_native_runtime_evidence.json
```
